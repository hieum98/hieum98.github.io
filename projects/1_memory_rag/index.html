Memory for Retrieval-Augmented Reasoning

An explicit working memory that decides which retrieved evidence to keep, update, or discard during multi-hop reasoning.

Multi-hop retrieval-augmented generation (RAG) has to keep a coherent picture of what it has found as the reasoning chain grows longer. This line of work gives the system an explicit working memory and learns how to manage it.

  • State-Aware RAG (Man et al., 2026): a trainable working memory (a Qwen3-4B extractor) that filters and updates retrieved evidence for multi-hop reasoning, with the retriever and generator frozen. The extractor is trained with LoRA SFT on about 70K MCTS-synthesized state-action pairs, then with GRPO using a Path-Outcome Dual Reward that also scores every reasoning step. It beats the best memory-augmented and RL-enhanced baselines by 8.6% and 9.3% on average across eight QA benchmarks. Code
  • Co-E (Man & Nguyen, 2026): keeps graph and text memory in sync during reasoning without any training. On an 8B open model, it beats comparable training-free baselines on six multi-hop QA benchmarks (+10.3 EM over HopRAG with GPT-4o on MuSiQue). Code

  1. ACL Findings
    Reasoning with Memory: Adaptive Information Management for Retrieval-Augmented Generation
    Hieu Man, Ro-ee Tal, Abhishek Kumar, Jaejin Cho, and Benjamin Hsu
    In Findings of the Association for Computational Linguistics: ACL 2026, Jul 2026
    Abs DOI Bib HTML PDF Code

    Multi-hop reasoning remains a fundamental challenge for Retrieval-Augmented Generation (RAG) systems. Recent approaches—from adaptive retrieval to agentic pipelines—struggle to maintain coherent intermediate reasoning states as chains grow longer. We introduce State-Aware RAG, a framework that addresses this limitation through an explicit working memory that serves as a dynamic cognitive workspace for reasoning. Our modular architecture features a lightweight, trainable extractor that learns to actively filter, consolidate, and update this working memory via a novel Path-Outcome Dual Reward paradigm, which balances local coherence with global strategy. The retriever and generator remain frozen, enabling plug-and-play flexibility. Experiments on eight QA benchmarks demonstrate state-of-the-art results, on average achieving +8.6% over the best memory-augmented baseline and +9.3% over the best RL-enhanced baseline. Our architecture generalizes seamlessly to stronger generators and retrievers without retraining, establishing dynamic memory management as a critical yet underexplored dimension for advancing RAG systems.

  2. arXiv
    Co-Evolving Graph and Text Memory for Training-Free Multi-Hop Question Answering
    Hieu Man and Thien Huu Nguyen
    arXiv preprint arXiv:2607.23278, 2026
    Abs arXiv Bib Code

    Multi-hop question answering requires coordinating relational and textual evidence across reasoning steps, a combination neither a text corpus nor a knowledge graph can supply alone. Prior work often emphasizes only part of this loop: graph-augmented RAG retrieves from a pre-built or query-updated graph, KGQA systems search within topic-centered subgraphs, and memory-augmented agents maintain evolving memories without continuously reconciling graph memory with textual context. We propose Co-E, a training-free system built around synchronized bidirectional graph-text working memory. A synchronization cycle consolidates textual memory, extracts relational triples into graph memory, and injects graph facts back into the generation context. Because both memories are maintained, they shape subsequent retrieval and generation. Evaluated on six multi-hop QA benchmarks, Co-E improves over comparable training-free open-backbone baselines and is competitive with larger or trained systems.
